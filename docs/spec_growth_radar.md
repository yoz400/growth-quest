# アバター成長レーダー

目的: 学習の積み重ねを自分の成長として見られるようにする。

- genres の登録順を再利用し、最大6軸ずつページ切替。1〜2ジャンルでは棒で表示。
- 累積XP・分数は既存genresを参照。ジャンルレベルは既存 xpForLevel と同じ累積閾値（Lv1開始、次Lvに100×現在Lv XP）から算出した表示専用値。
- レーダーは累積XP、全ジャンル共通の目盛り。現在と30/90日前の同じ日付終了時を比較。
- 日別ジャンル分数の合計と累積XP/分数が一致し、比較日以前の履歴がある場合のみ過去を復元。欠損・不一致・新ジャンルは履歴不足。未知の値はゼロで描かない。
- 全データの読み取りのみ。保存キー、XP加算、タイマー、オトモン等は変更しない。
- グラフの軸とジャンルボタンから詳細を選択。キーボード操作可能。

受け入れ基準・テスト:
1. ジャンル追加/削除と再表示に追従、0/1/2/6/7/20ジャンルで表示可能。
2. 現在値と既存レベル規則が一致、休止しても現在値は不変。
3. 完全履歴/履歴不足/不一致/30日/90日境界で未知の値を生成しない。
4. 表示・切替でlocalStorageは変更されない。
5. 起動・アバター・設定・図鑑・カレンダー・タイマーと既存tests.htmlを検証。
6. 依存追加なし、キャッシュ番号更新、読み込み順検査通過。
