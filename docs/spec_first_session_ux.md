# 仕様書：初回体験と集中の入口・出口の改善

2026-10-18。ユーザー依頼：実使用レビューで挙げた5点をすべて改善する。

## 対象と受け入れ基準

1. 5分集中モードを追加する。5分で通常の完了・記録・振り返りへ進み、休憩は自動開始しない。
   保存済みの起動モードは維持し、設定がない場合の初期値を5分にする。
   実行中・一時停止中の再読み込みでも5分モードを復元する。
2. 手動終了を「終了して記録」に変更する。1分未満を記録しない既存ルールを説明する。
   開始・一時停止・再開・完了の既存機構を使用し、記録や報酬を重複させない。
3. 初回召喚を冒険者・名前・テーマの3画面にする。名前・テーマは省略可能。
   習慣はホームで追加できると案内する。既存の再設定用フローは維持する。
   初回召喚の直後に別の自動チュートリアルを重ねない。設定からの手動ガイドは残す。
4. 週次レビュー通知は非表示時にサイズによらず完全に隠す。
   初回案内中・機能未解放・対象週に学習記録がない場合は誘導も通知ドットも出さない。
   解放済みかつ対象週に学習記録がある場合の通常のレビュー誘導は維持する。
5. 初回案内・使い方説明の「装備」への誘導を現行のアイテム・オトモン等に改める。
   撤去済み機能を復活させず、既存保存データは変更しない。

## 実装・確認方針

- 新しい保存キー・モーダルは作らない。docs/AI/は編集しない。
- 5分モードは既存MODESへ追加し、既存タイマーの完了経路を利用する。
- モードはキーボード操作可能なボタンにする。狭い画面では2列に収める。
- 新規のローカル検証環境で初回3画面・5分完走・途中終了・再読み込み復元を確認する。
- 設定・図鑑・カレンダーの開閉、狭い画面での表示、ブラウザエラーを確認する。
- CSS/JS変更後に tools/bump_version.sh を実行する。
- 実装依頼の時点では確認済みの差分を引き渡す。追加依頼「本番に公開して」により、コミット・本番公開を行う。
