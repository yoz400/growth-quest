## 愛着につながる関わり方

中心に置く体験: 習性を知る → 一緒に行動する → その子らしい反応が返る → 思い出が残る → 紹介文の意味が深まる。

### 1. 紹介文と反応をつなぐ

- こだまスライム: 学習完了時に「今日の言葉、もう一回聞きたいな」。内容入力は任意。
- ころころ岩モグ: 片付けのクエスト完了時に「ここ、丸くなれるくらい広くなった！」。
- みならいフェニックス: 休んだあとの再開時に「ぼくも今日、もう一度飛んでみる」。
- 基本の反応を少数用意し、特別な節目で個別の反応を出す。毎回割り込む表示は避ける。

### 2. 一緒に過ごした事実を記録する

- 「初めて一緒に集中した日」「一緒に5回やりきった日」などを、相棒との思い出として残す。
- 実際に相棒にしていた期間の行動だけを記録する。後から選んだ子に昔の成果を帰属させない。
- 初期案は日付と定型文だけ。自由入力や学習内容の収集は必須にしない。

### 3. 絆で生態の続きがわかる

- 基本紹介は出会ったときから読める。
- 絆が進むと「観察メモ」を追加する。数値だけでなく、その子の意外な一面を知る楽しみをつくる。
- 例・ぷちミミック: 「宝箱の奥の品は、値段ではなく、もらった順に並んでいた」。
- 例・月下白虎: 「昼寝の場所を決めるときだけは、何度も落ち着かずに歩き回る」。
- 新しい設定の量を考慮し、まず少数の子で試してから100体へ広げる。

### 4. ふれあいに選択と返事をつける

- 「今日の小さな達成を話す」「ひと休みする」「好きなものを聞く」など、選んだ行動に合う反応を返す。
- 食べ物の好みや仕草は少数から固定し、毎回性格が変わらないようにする。
- 連打するほど有利になる報酬は付けず、自然に寄りたくなる場所にする。

### 5. 離れていた日にも安心して戻れる
